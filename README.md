# 基于多模态的封口质量检测系统（银边 + 异物检测）

本项目面向塑料包装袋高温热封工序，采用 **YOLO 目标检测** 实现封口质量的自动化在线检测，支持 **银边漏出** 与 **异物** 两类缺陷的实时识别与报警。

---

## 功能特性

- **银边检测**：检测内袋铝箔是否从封口漏出
- **异物检测**：检测封口区域内的黑点、杂质等
- **GUI**：
  - 支持选择预置模型或加载自定义权重（.pt）
  - 实时调节银边/异物置信度阈值
  - 文件夹批量检测、图片浏览、检测结果可视化
  - 日志记录与导出

## 图形界面使用

### 启动程序

```bash
python app.py
```

### 界面功能说明

1. **模型选择**  
   - 下拉框选择预置的 YOLOv8 或 YOLOv11 权重  
   - 点击「浏览...」按钮可加载自定义 `.pt` 权重文件

2. **置信度阈值调节**  
   - 银边阈值：推荐 0.3～0.5（滑动条实时调整）  
   - 异物阈值：推荐 0.6～0.8

3. **图片文件夹选择**  
   - 点击「选择文件夹」加载待检测图片目录（支持 `.jpg`、`.png`、`.tif` 等）

4. **图片浏览**  
   - 「上一张」「下一张」切换图片，切换时自动清除上次检测结果

5. **检测**  
   - 点击「检测当前图片」进行推理  
   - 图像区域显示带检测框的结果  
   - 日志区输出检测结论（如“检测到银边”“检测到异物”及最高置信度）

6. **日志与状态**  
   - 日志区记录操作历史、检测结果和错误信息  
   - 状态栏显示当前图片序号、模型加载状态等

## 性能指标

基于验证集（500 张图片）的测试结果：

| 模型      | 类别         | mAP50 | mAP50-95 | Precision | Recall |
|-----------|--------------|-------|----------|-----------|--------|
| YOLOv8    | silver_edge  | 0.839 | 0.337    | 0.863     | 0.757  |
| YOLOv8    | foreign_object | 0.995 | 0.847    | 0.986     | 1.000  |
| YOLOv11   | silver_edge  | 0.810 | 0.371    | 0.747     | 0.820  |
| YOLOv11   | foreign_object | 0.995 | 0.819    | 0.973     | 1.000  |

- **异物检测已达生产部署标准**（mAP50 ≈ 0.995，召回率 100%）
- 银边检测定位精度（mAP50-95）有提升，可结合阈值调节平衡漏检与误报

## 常见问题

**Q: 运行时提示 `No module named 'ultralytics'`**  
A: 请先执行 `pip install ultralytics`。

**Q: GUI 加载模型时卡住**  
A: 模型加载在后台线程执行，请稍等。若长时间无响应，检查 `.pt` 文件是否损坏或路径不正确。

**Q: 检测结果不理想**  
A: 尝试降低银边阈值（如 0.25）或提高异物阈值（如 0.7），或更换其他模型权重。

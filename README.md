# 基于多模态的封口质量检测系统（银边 + 异物检测）

本项目面向塑料包装袋高温热封工序，采用 **可见光（YOLO 目标检测）+ 红外热成像（温度分析）** 的多模态方案：可见光检测 **银边漏出** 与 **异物** 两类缺陷，红外图像分析封口区域温度分布并判定异常。

---

## 功能特性

- **银边检测**：检测内袋铝箔是否从封口漏出（YOLOv8/v11）
- **异物检测**：检测封口区域内的黑点、杂质等
- **红外温度分析**：在伪彩红外图上定位封口区域，统计温度均值/方差并判定异常（`thermal_analysis.py`）
- **GUI**：
  - 支持选择预置模型或加载自定义权重（.pt）
  - 实时调节银边/异物置信度阈值
  - 文件夹批量检测、图片浏览、检测结果可视化
  - 日志记录与导出

## 数据预处理

可见光原始图分辨率为 2448×2048，包装袋(封口区域)仅占画面中部偏上位置：

```python
img = cv2.imread(str(p))
cropped = img[500:1700, 200:2400]   # ROI: y0:y1, x0:x1 -> 2200×1200
resized = cv2.resize(cropped, (1184, 640))
```

- **垂直方向**：保留 500~1700 行，上方留足余量(银边位于封口最上方，且异物/内容物可能向上露出)，下方裁掉无用的袋体下半；
- **水平方向**：保留 200~2400 列(约 90% 宽度)，封口横贯全宽，水平仅做少量裁剪；
- **等比缩放**至 1184×640(2200:1200 ≈ 1184:640)，无纵横比失真。

## 图形界面使用

### 启动程序

```bash
python app.py
```

### 界面功能说明

1. **模型选择**  
   - 下拉框选择预置的 YOLOv8 或 YOLOv11 权重  
   - 点击「浏览...」按钮可加载自定义 `.pt` 权重文件

2. **置信度阈值调节**  
   - 银边阈值：推荐 0.3～0.5（滑动条实时调整）  
   - 异物阈值：推荐 0.6～0.8

3. **图片文件夹选择**  
   - 点击「选择文件夹」加载待检测图片目录（支持 `.jpg`、`.png`、`.tif` 等）

4. **图片浏览**  
   - 「上一张」「下一张」切换图片，切换时自动清除上次检测结果

5. **检测**  
   - 点击「检测当前图片」进行推理  
   - 图像区域显示带检测框的结果  
   - 日志区输出检测结论（如“检测到银边”“检测到异物”及最高置信度）

6. **日志与状态**  
   - 日志区记录操作历史、检测结果和错误信息  
   - 状态栏显示当前图片序号、模型加载状态等

## 性能指标

基于验证集（100 张图片）的测试结果：

| 模型      | 类别         | mAP50 | mAP50-95 | Precision | Recall |
|-----------|--------------|-------|----------|-----------|--------|
| YOLOv8    | silver_edge  | 0.839 | 0.337    | 0.863     | 0.757  |
| YOLOv8    | foreign_object | 0.995 | 0.847    | 0.986     | 1.000  |
| YOLOv11   | silver_edge  | 0.810 | 0.371    | 0.747     | 0.820  |
| YOLOv11   | foreign_object | 0.995 | 0.819    | 0.973     | 1.000  |

- **异物检测已达生产部署标准**（mAP50 ≈ 0.995，召回率 100%）
- 银边检测定位精度（mAP50-95）有提升，可结合阈值调节平衡漏检与误报

### 银边定位精度分析

银边是宽高比约 40:1 的细长目标(典型标注框 700×16~19 像素)。在 `imgsz=640` 下，1184×640 被缩放到约 640×346，银边高度被压缩到 9~10 像素，经特征图下采样(8/16/32)后仅剩 1~2 像素，定位精度受限于特征图分辨率。改进方向：

- 银边单独使用 `imgsz=1280` 训练；
- 或对封口顶部切高分辨率子 ROI 训练银边专用模型。

## 红外温度分析

### 思路

伪彩红外图(蓝冷红热)取热信号 `heat = R - B`：

1. 行均值投影定位封口条带垂直位置，以暖区(`R-B ≥ 0`)确定条带完整厚度；
2. 列投影质心确定水平中心，结合先验宽度(0.85×图宽)确定水平范围；
3. 统计区域内温度均值、方差、峰值、厚度；
4. 以前 N 张标准图建立基准，温度特征用 z-score、位置用绝对容差判定异常。

### 运行

```bash
python thermal_analysis.py
```

输出：封口框可视化 + `results/infrared_analysis/report.json`(完整特征与偏离分数)。

### 关键假设

1. 封口是图中温度最高的横贯条带，与背景有足够温差；
2. 封口条带方向已知(行投影方向与条带垂直)；
3. 图中只有一个主高温区；
4. 像素值与温度单调相关(若需绝对温度，需标定关系 `T = a·raw + b`)；
5. 仅处理 ACamera 组数据(DCamera 为另一路相机/工位，需单独建基准)。

## 常见问题

**Q: 运行时提示 `No module named 'ultralytics'`**  
A: 请先执行 `pip install ultralytics`。

**Q: GUI 加载模型时卡住**  
A: 模型加载在后台线程执行，请稍等。若长时间无响应，检查 `.pt` 文件是否损坏或路径不正确。

**Q: 检测结果不理想**  
A: 尝试降低银边阈值（如 0.25）或提高异物阈值（如 0.7），或更换其他模型权重。
